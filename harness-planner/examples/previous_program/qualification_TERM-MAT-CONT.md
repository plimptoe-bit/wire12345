# Tool qualification sheet — FIX-HT-0640 for TERM-MAT-CONT

- Terminal / joint: TERM-MAT-CONT (Ethernet data contact 0.13-0.35 mm2 for shielded header system)
- Governing spec: [application spec: SYN-APPSPEC-2001, Rev C, table 3]
- Tool: FIX-HT-0640 (SynTool (fixture)) — Hand crimp tool 0.13-0.5 mm2 F-crimp small pitch
- Tool restrictions on file: repair and samples only per SYN-IS-411 Rev A
- Harnesses affected: D-1002

## Acceptance targets (from the application spec)
- Crimp form: F
- Crimp height: 0.72 ± 0.03 mm
- Crimp width: 0.9 ± 0.03 mm
- Pull force: ≥ 50 N
- Strip length: 2.6 mm

## Protocol
1. Dimensional check on 10 samples: crimp height and width, recorded individually.
2. 3 cross-sections: conductor compression, bellmouth, cut-off per the spec's figures.
3. Pull test to the spec minimum on 5 samples.
4. Visual inspection per the spec's inspection figures.
5. Shielded/impedance-controlled joint: link test or VNA sweep per the customer's test requirement.
6. Sealed system: seal-fit check on the finished termination (where applicable).
7. Record results on this sheet; attach to the program file and update the tool inventory (certification date, cycle count).

> Note: if the application spec restricts tooling to named tools, a customer deviation may be needed — raise it as an open item before series use.
