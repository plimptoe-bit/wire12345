# Tool qualification sheet — FIX-HT-0640 for TERM-NANO-050

- Terminal / joint: TERM-NANO-050 (Small-pitch F-crimp terminal 0.13-0.5 mm2, Sn, insulation 1.2-1.6 mm)
- Governing spec: [application spec: SYN-APPSPEC-1001, Rev B, table 2]
- Tool: FIX-HT-0640 (SynTool (fixture)) — Hand crimp tool 0.13-0.5 mm2 F-crimp small pitch
- Tool restrictions on file: repair and samples only per SYN-IS-411 Rev A
- Harnesses affected: D-1003, D-1005

## Acceptance targets (from the application spec)
- Crimp form: F
- Crimp height: 0.78 ± 0.03 mm
- Crimp width: 0.95 ± 0.03 mm
- Pull force: ≥ 60 N
- Strip length: 2.8 mm

## Protocol
1. Dimensional check on 10 samples: crimp height and width, recorded individually.
2. 3 cross-sections: conductor compression, bellmouth, cut-off per the spec's figures.
3. Pull test to the spec minimum on 5 samples.
4. Visual inspection per the spec's inspection figures.
5. Sealed system: seal-fit check on the finished termination (where applicable).
6. Record results on this sheet; attach to the program file and update the tool inventory (certification date, cycle count).
