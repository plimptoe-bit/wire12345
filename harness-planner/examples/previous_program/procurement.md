## How to order
- `procurement_octopart.csv` → upload to Octopart's BOM tool to compare distributors and push to carts.
- `procurement_digikey.csv` → DigiKey myLists upload (shareable list).
- `procurement_mouser.csv` → Mouser BOM tool / Project Manager upload.

Upload-page URLs are found by search in run mode and recorded here only when verified; none are fabricated. If DigiKey/Mouser/Nexar API keys are configured, the cart can be built programmatically instead.
